# Osztályozó vizsga tematika

**Webprogramozás – 2026/2027. tanév, I. félév**

A vizsga anyaga két részből áll: az előző tanév anyagának ismétléséből (HTML és CSS, JavaScript I.) és a félév új tananyagából (JavaScript II.).

---

## I. Ismétlés

### 1. HTML és CSS

#### Ismeretek

- Táblázatok létrehozása és formázása
- Szemantikus elemek (`article`, `aside`, `main`, `header`, `footer`, `section`) alkalmazása
- Médiaelemek alkalmazása
- Metaelemek és SEO-alapok
- A viewport metaelem
- Konkurens stílusok érvényesítési sorrendje (specificitás)

#### CSS-tulajdonságok és -eszközök

- `border-collapse`
- `nth-child`
- media query
- színek (colors)
- `opacity`
- gradiensek (gradients)
- `box-shadow`
- `outline`
- `text-shadow`
- `border-radius`
- szelektorok: `>`, `+`, `~`
- attribútumszelektorok
- `::before`, `::after`
- Flexbox
- CSS Grid
- `transform`

### 2. JavaScript I.

- JavaScript kód futtatása konzolon
- Elemi és összetett adattípusok (Number, String, Array, Boolean, undefined, null, Object, Map, Set); értékadás, aritmetikai és logikai műveletek, kifejezések kiértékelése
- Reguláris kifejezések
- Változók és konstansok deklarálása (`var`, `let`, `const`), láthatóságuk
- Vezérlési szerkezetek (`if`, `while`, `for`, `for…in`, `for…of`, `switch`, `break`)
- Template literal (sablonszöveg)
- Függvények deklarálása, arrow function
- Objektumok webes környezetben, tulajdonságok és metódusok; DOM, node-ok (element, attribute, text)
- Elemek elérése, módosítása és létrehozása
- Események és eseményfigyelők (`onClick`, `onLoad`, `onBlur`, `onFocus`)
- Űrlapelemek (`form`, `input`, `select`, `option`, `textarea`, `label`) elhelyezése és interaktív kezelése

## II. Új tananyag

### 3. JavaScript II.

#### Objektumok és tömbök kezelésére szolgáló ES6 függvények és operátorok

- Tömbmetódusok: `forEach`, `map`, `filter`, `reduce`, `find`, `findIndex`, `some`, `every`, `includes`, `sort`
- Objektummetódusok: `Object.keys`, `Object.values`, `Object.entries`
- Spread és rest operátor (`...`)
- Destrukturálás (tömbök és objektumok)

#### Hibakeresés a JavaScript kódban, a kód tesztelése

- A böngésző fejlesztői eszközei, a konzol használata (`console.log`, `console.table`, `console.error`)
- Töréspontok, lépésenkénti futtatás, változók értékének figyelése
- Hibatípusok (szintaktikai, futásidejű, logikai hiba)
- Kivételkezelés: `try…catch…finally`, `throw`
- A kód tesztelése különböző bemeneti adatokkal

#### Aszinkron futás és callback-ek

- Szinkron és aszinkron végrehajtás különbsége
- Callback függvények fogalma és használata
- Időzítők: `setTimeout`, `setInterval`, `clearTimeout`, `clearInterval`
